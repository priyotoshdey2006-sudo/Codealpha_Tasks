# CodeAlpha Event Registration System

A professional REST API-based Event Registration System developed using Node.js, Express.js, and SQLite as part of the CodeAlpha Backend Development Internship.

## Features

- Create events
- View all events
- View event details
- Update events
- Delete events
- Register participants for events
- Prevent duplicate registrations
- Check event capacity
- View event registrations
- Cancel registrations
- SQLite database
- RESTful API
- JSON responses
- CORS support
- Input validation
- Proper HTTP status codes

## Technologies Used

- Node.js
- Express.js
- SQLite3
- CORS
- REST API
- JavaScript
